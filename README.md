# The Afterlife

![Unity](https://img.shields.io/badge/Unity-6000.0.4f1-black?logo=unity)
![C#](https://img.shields.io/badge/C%23-Game%20Scripts-239120?logo=csharp)
![Status](https://img.shields.io/badge/Status-Prototype-orange)

**The Afterlife** — прототип двухмерной RPG с видом сверху и пиксельной графикой, созданный на Unity. Игрок исследует локацию, сражается с противниками, собирает опыт и монеты, повышает уровень и открывает доступ к новым областям.

> Репозиторий содержит исходный проект Unity, а не готовую сборку игры.

## Возможности

- **Передвижение и бой:** управление персонажем, атака мечом в направлении курсора, анимации движения и получения урона
- **Противники:** скелеты с поведением на базе NavMesh: патрулирование случайных точек, преследование игрока, атака и смерть
- **Здоровье:** шкала HP, получение урона с временным интервалом между попаданиями, перезапуск указанной сцены при смерти персонажа
- **Опыт и уровни:** выпадающие с врагов объекты опыта, шкала XP и повышение уровня
- **Прогрессия:** двери открываются при достижении заданного уровня персонажа
- **Сундуки и монеты:** открытие сундуков, получение валюты и сохранение количества монет через `PlayerPrefs`
- **Визуальная часть:** пиксельные окружения, анимации персонажа, скелетов и ударов мечом

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | `W` `A` `S` `D` или стрелки |
| Атака мечом | Левая кнопка мыши |
| Направление персонажа и меча | Положение курсора |
| Открыть сундук рядом с персонажем | `E` |

## Технологии

- **Unity:** `6000.0.4f1` (Unity 6)
- **Язык:** C#
- **Графика:** 2D Pixel Art, Universal Render Pipeline (URP)
- **Управление:** Unity Input System `1.8.2`
- **Навигация противников:** AI Navigation `2.0.0`, NavMesh
- **Камера:** Cinemachine `3.1.0` (подключённый пакет)
- **Интерфейс:** Unity UI и TextMesh Pro

## Запуск проекта

1. Установите [Unity Hub](https://unity.com/download) и редактор **Unity 6000.0.4f1**
2. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/furziktv/The-Afterlife.git
   ```

3. Откройте **Unity Hub → Add project from disk** и выберите папку `The-Afterlife`
4. Дождитесь импорта ассетов и восстановления пакетов через Package Manager
5. Откройте сцену `Assets/Scenes/WitchWilage.unity`
6. Нажмите **Play** для запуска в редакторе

Сцена `WitchWilage.unity` указана в **Build Settings** как включённая. В `Assets/Scenes/` также есть `Level1.unity`.

## Как устроены основные системы

**Бой.** `GameInput` получает событие нажатия кнопки мыши и передаёт его `Player`. Игрок вызывает `Attack()` у активного меча, а попадания обрабатывает `Sword`, вызывая `TakeDamage()` у противника.

**Поведение врагов.** `EnemyAI` использует конечный автомат с состояниями `Idle`, `Roaming`, `Chasing`, `Attacking`, `Death`. Перемещение реализовано через `NavMeshAgent` с настройками для двумерного пространства.

**Прогрессия.** `PlayerHP` отвечает за здоровье, получение опыта и повышение уровня. `DoorManager` периодически проверяет уровень игрока и открывает подходящие двери.

**Награды.** `EnemyLoot` создаёт объекты добычи после смерти противника. `XP` начисляет опыт при соприкосновении с игроком. Сундуки увеличивают баланс монет; `Coins` сохраняет его с помощью `PlayerPrefs`.

## Состояние разработки

Это игровой прототип. Некоторые системы реализованы в базовом виде и могут нуждаться в доработке, балансировке и тестировании. Наличие ассетов и демонстрационных сцен в репозитории не означает, что все они задействованы в основной игровой сцене.

## Используемые ассеты

В проекте присутствуют материалы и примеры из сторонних наборов:

- **Cainos / Pixel Art Top Down - Basic** — окружение и 2D-ресурсы
- **Bandits - Pixel Art** — спрайты, анимации и демонстрационные материалы
- **TextMesh Pro** — интерфейсный текст

Права на сторонние ресурсы принадлежат их авторам. Перед повторным использованием или распространением ассетов проверьте условия соответствующих лицензий.
